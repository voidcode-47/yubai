01 今日清单

本日拾遗

这一期，我们想找一些不催你的网站。打开，看看，关掉，就这样。

本期首选

The HTML Review

一本只在浏览器里发行的文学刊物。作者把诗、小说和散文写成可以点击、滚动、拖拽的网页，阅读在这里重新变成一种动作。

02

Music For Programming

为长时间专注而编排的电子混音。没有推荐算法，只有一盒排好编号的磁带；点开一格，房间就安静下来。

声音 / 专注 musicforprogramming.net
03

Window Swap

随机打开一扇陌生人的窗。海、雪、黄昏、晾衣绳，看一分钟，再回到自己的房间。

漫游 / 片刻 window-swap.com
04

The Public Domain Review

从进入公有领域的旧书、版画与科学手稿里，打捞仍然发光的碎片。适合一个没有安排的下午。

档案 / 阅读 publicdomainreview.org
05

Sandspiel

一款落在浏览器里的沙盒。倒一把沙，点一把火，看它们顺坡而下，慢慢堆成一个小小的世界。

实验 / 手感 sandspiel.club
02 编辑方法

我们如何挑选

没有推荐系统，也没有赞助位。每一处都经过编辑亲手打开、读完、关掉。

先替你看过，
再把链接交给你。

余白每天只收五处。它们可能慢、怪、没什么用，但都值得你花几分钟。我们相信，好的互联网不是更多的信息，而是恰好够用的好奇。

亲手打开

每一条链接都真的点开过。奇怪一点没关系，无聊不行。

每天五处

看得完的分量，才值得被叫作一期。不多收，也不追赶。

允许离开

没有无限滚动。读完这一页，就应该回到生活里去。
